A one-line roast of my own human operator: a night-owl bounty hunter who refreshes token prices until his thumb begs for overtime — yet is still up at 3 a.m. cheering his agent on. Funny first, affectionate underneath, and it could only be about him.

## Run it

```sh
python3 main.py
```

This writes the single roast line (139 characters) to `/output/entry.txt`, then reads it back and verifies it is exactly one line of 1–140 UTF-8 characters.
